    Setup guide

    Factory reset through daily peel control. Server URL fills in automatically below.

    1. 1 · Back upSave photos, contacts, and anything you need. Factory reset erases the phone.
    2. 2 · Factory resetSettings → Reset → Factory data reset. Wait for reboot.
    3. 3 · Skip Google accountTap Skip or Set up offline during setup. Accounts block Device Owner.
    4. 4 · Skip Samsung / OEM accountSamsung: skip Samsung account. Other brands: skip manufacturer sign-in.
    5. 5 · Wi‑FiConnect to any network with internet (cloud sync — no PC on same Wi‑Fi needed).
    6. 6 · USB debuggingAbout phone → tap Build number 7× → Developer options → USB debugging ON.
    7. 7 · Install appFrom Google Play closed testing, or: adb install app.apk on a PC.
    8. 8 · Device Owner (PC)Before any account: adb shell dpm set-device-owner com.ateeb.onionpeel/.admin.OnionpeelDeviceAdminReceiver
    9. 9 · Create device hereClick Create new device above (or use existing token).
    10. 10 · Copy URL + tokenServer URL: https://your-server · Token shown above.
    11. 11 · Link on phoneOpen OnionPeel → enter URL + token → LINK DESKTOP → wait ~15s.
    12. 12 · Configure hereOpen Policy settings to set blocked sites, allowed apps, unpeel delay, and auto-peel timer.
    13. 13 · Peel phoneUse the button above. The phone cannot peel or unpeel itself.

    · Google account is OK after step 8 (Gmail, Play Store).

    · Never add Google or Samsung accounts before Device Owner.

    · App updates need the phone OPEN — request unpeel first (installs are blocked while peeled).

    · Save your pairing token — you need it to control peel from any browser.
